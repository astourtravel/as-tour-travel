## Test locally
Open `index.html` in a browser. Submit the booking form with test details; it should open WhatsApp with a prefilled booking request. The customer must press Send in WhatsApp.

## Publish free
Upload all three website files to the root of a GitHub repository, then open Settings → Pages → Deploy from a branch → `main` → `/ (root)` → Save. GitHub Pages will provide a public URL. Cloudflare Pages can also host this static website.

## Before publishing
- Replace the sample customer testimonials in `index.html` with genuine customer reviews. They are clearly marked as sample content.
- Confirm that the airport pickup claims and all listed routes match the actual service offered.
- The language switch currently translates the navigation labels only. The rest of the website remains in English until Hindi translations are added.
- This is a static site. It sends booking requests to WhatsApp; it does not store bookings in a database, calculate live fares, or confirm live vehicle availability.
